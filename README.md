# 🌟 Pixel Invitess — Premium Digital Invitations

A highly sophisticated, premium, and fully responsive digital invitation platform. Designed with an elegant aesthetic featuring **Rose Gold, Warm Cream, and Ivory** tones, tailored for luxury event invites.

The website includes custom smooth animations, dynamic video sliders, petal-falling effects, and an interactive WhatsApp-integrated order booking system.

---

## ✨ Features

* **Premium Visual Design:** Crafted with high-end typography (`Cormorant Garamond`, `Great Vibes`, `Jost`) and luxury color palettes.
* **Built-in Content Protection:** Integrated JavaScript security layers to minimize inspection, block right-clicks, disable common screenshots/inspect hotkeys, and blur the layout dynamically on `PrintScreen`.
* **Interactive Booking System:** Multi-step sleek modal popup that collects client details and passes them perfectly formatted to WhatsApp.
* **Performance Optimized:** Clean, lightweight CSS transitions and custom Intersection Observer (`scroll reveal`) for butter-smooth animations.
* **Immersive FX:** Micro-interactions and subtle organic ambient elements (falling petals).

---

## 🛠️ Tech Stack

* **Frontend:** Semantic HTML5, Advanced CSS3 (Custom Variables, Keyframes, Flexbox/Grid)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Integrations:** WhatsApp Business API Routing
